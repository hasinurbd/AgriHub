# 🌾 AgriHub - Agriculture Supply Chain Management System

AgriHub is a digital agricultural marketplace that connects farmers, buyers, suppliers, and transport providers through a secure and transparent platform. It simplifies agricultural trade by improving market access, price transparency, and supply chain efficiency across Bangladesh.

## 🚀 Live Demo

🔗 https://agri-hub-alpha.vercel.app/

## 📖 Overview

AgriHub is designed to modernize the agricultural ecosystem by creating a trusted digital network where farmers and businesses can trade products efficiently. The platform reduces reliance on intermediaries, promotes fair pricing, and helps stakeholders manage agricultural transactions with greater transparency and convenience.

---

## ✨ Features

- User Authentication and Authorization
- Farmer, Buyer, Supplier, and Transporter Profiles
- Agricultural Product Listings
- Digital Marketplace
- Product Search and Filtering
- Supply Chain Management
- Secure Transactions
- Logistics and Delivery Coordination
- Responsive and User-Friendly Interface
- Real-Time Agricultural Trade Network

---

## 🎯 Problem Statement

Small-scale farmers in Bangladesh often struggle to find reliable buyers, fair market prices, trusted suppliers, and efficient logistics services. Traditional agricultural trading is fragmented, lacks transparency, and involves multiple intermediaries, reducing farmers' profits and limiting market access.

AgriHub addresses these challenges by creating a unified digital platform that connects farmers, buyers, suppliers, and transport providers, enabling secure, transparent, and efficient agricultural trade.

---

## 💡 Solution Description

AgriHub is a web-based agricultural trade platform that brings all key stakeholders into one trusted ecosystem. Users can create verified profiles, list or search for agricultural products, compare prices, and communicate directly with trading partners.

The platform improves transparency through quality-focused listings, easier market access, and streamlined supply chain processes. By integrating trading, supplier management, and logistics support, AgriHub enables efficient agricultural commerce across Bangladesh.

# 📦 Installation

## Clone the Repository

```bash
git clone https://github.com/hasinurbd/AgriHub.git
cd AgriHub
```

## Install Dependencies

```bash
npm install
```

or

```bash
npm install --legacy-peer-deps
```

---

## Configure Environment Variables

Create a `.env.local` file in the project root:

```env
MONGODB_URI=your_mongodb_connection_string
NEXT_PUBLIC_API_URL=http://localhost:3000
JWT_SECRET=your_secret_key
```

Replace the above values with your actual configuration.

---

## Run Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

---

# 🏗 Production Build

Build the application:

```bash
npm run build
```

Start production server:

```bash
npm start
```

---

# 🌐 Deployment Guide

## Deploy with Vercel

### Option 1: GitHub Integration

1. Push the project to GitHub.
2. Sign in to Vercel.
3. Click **New Project**.
4. Import the AgriHub repository.
5. Configure environment variables.
6. Click **Deploy**.

### Option 2: Vercel CLI

Install Vercel CLI:

```bash
npm install -g vercel
```

Deploy:

```bash
vercel
```

Deploy to production:

```bash
vercel --prod
```
